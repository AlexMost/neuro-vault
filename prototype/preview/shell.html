PROTOTYPE — structured preview for read_notes (issue 247)

Throwaway. Four candidates for what content: 'preview' returns, on public repo notes and synthetic edge cases, plus size aggregates over a ~1k-note vault (numbers only).

  • A — today: 500-char prefix + truncated, plus a lines echo (first..last line the prefix touches).
  • B — outline + prefix: A plus the outline from 246 (outline, preamble, collapsed). Additive: existing fields unchanged. Ladder becomes frontmatter ⊂ outline ⊂ preview ⊂ full.
  • C — structured array: preview: [{ heading, level, lines, excerpt }] — outline entry + first ≤160 chars of the heading's own text; per-note total 1200 B (variants: last-first degrade, 2 KB total). Over budget, excerpts drop (deepest first), structure never does.
  • D — markdown skim: one string in content: heading lines verbatim, the C excerpts under them, spans inlined as <!-- 14-22 -->; cut fences re-closed.
