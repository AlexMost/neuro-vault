Delivery is three PRs. Groups 1–3 are **sequential with respect to each other** —
group 1 must be reviewed and merged before group 2 starts, because group 2 lands
the aggregate move on top of the rewritten write path. Within a group,
parallel-safety is marked per group.

Each task is a TDD unit: write the failing test, implement, refactor. Tests reach
tools through `registerTool(buildXTool(deps))` and the `test/_gate.ts` helpers,
never `buildXTool(deps).handler` (ADR-0015). Prefer DI over module-level mocks.
