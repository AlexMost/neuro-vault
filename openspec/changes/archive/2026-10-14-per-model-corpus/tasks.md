# Tasks — per-model-corpus

One PR, `Closes #146`. Every task keeps `npm test`, `npm run lint` and `npm run typecheck` green at its commit. Contention, liveness and time are injected (`pid`, `isAlive`, `sleep`, `now`, fs functions) — no module-level mocks.

Ordering: group 1 is sequential and blocks everything. Group 2's three tasks are **parallel-safe** with each other (one new file each, no shared state). Group 3 starts after group 2; inside it, 3.1 comes first, then 3.2, 3.3 and 3.4 are **parallel-safe** with each other (disjoint files). Group 4 (docs) is sequential after group 3. Group 5 is sequential and last.

**Parallel dispatch needs one worktree per task.** Parallel-safe tasks touch disjoint files, but every task runs project-wide gates (`npm run typecheck`, `npm run lint`) and commits. In one shared worktree a sibling's half-written file breaks those gates and simultaneous commits collide. So dispatch a parallel group only with each task in its own worktree off the group's base commit, then merge them back in task order. Without that, run the group's tasks one after another.
